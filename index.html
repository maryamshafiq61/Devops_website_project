🚀 Automated Website Deployment (SDC-P01) This is a real-world DevOps project where I have successfully hosted and automated a web application. I configured an AWS EC2 Instance running Ubuntu Linux, managed permissions using AWS IAM, and installed Nginx to serve the website files. To achieve full automation, I implemented a CI/CD pipeline using GitHub Actions. Whenever new code is pushed to this GitHub repository, the pipeline automatically triggers, authenticates via SSH, and deploys the updated website files straight to the production server without any manual intervention.
